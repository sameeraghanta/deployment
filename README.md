# Dynamic Web Application

A basic dynamic web application developed as part of a two-day hands-on workshop on building dynamic web applications from fundamentals to cloud hosting.

## 🚀 Project Overview

This project helped me gain practical experience in developing and deploying a web application from scratch.

I worked on the frontend, backend, database integration, and deployment process.

## 🛠️ Technologies Used

- React.js
- Node.js
- Express.js
- MongoDB
- Netlify

## 📚 What I Learned

- Building a frontend using React.js
- Creating backend services using Node.js and Express.js
- Working with MongoDB
- Connecting frontend and backend
- Understanding the complete web application workflow
- Deploying a web application from scratch
